Copie 是一个轻量的 macOS 菜单栏工具，让你通过简单的鼠标操作快速完成全选、复制和粘贴。

当前版本：**1.0**

## 下载

请前往 [GitHub Releases](https://github.com/qdaju/Copie/releases) 下载最新的 `Copie.dmg`。

## Copie 能做什么

- 长按鼠标左键，快速全选当前内容
- 拖动选中文字后点击右键，快速复制
- 点击鼠标中键，快速粘贴
- 复制成功后显示简洁的文字提示
- 自由调整长按触发时间
- 支持中文和英文菜单
- 支持登录时自动启动
- 常驻菜单栏，不占用 Dock 空间

## 安装

1. 下载并打开 `Copie.dmg`。
2. 将 `Copie.app` 拖入“应用程序”文件夹。
3. 从“应用程序”中启动 Copie。
4. 根据提示开启辅助功能权限。

建议始终从“应用程序”文件夹启动 Copie。应用位置保持不变后，macOS 的辅助功能授权会更加稳定。

如果 macOS 提示无法确认开发者，请确认安装包来源可信，然后在“应用程序”中右键点击 Copie，选择“打开”。

> Copie 1.0 暂未经过 Apple Developer ID 签名和公证，因此首次启动时可能出现 macOS 安全提示。

## 首次使用

Copie 需要辅助功能权限才能监听鼠标操作并执行全选、复制和粘贴。

1. 启动 Copie。
2. 打开“系统设置 → 隐私与安全性 → 辅助功能”。
3. 找到 Copie，并打开右侧开关。
4. 返回桌面即可开始使用。

Copie 不会显示在 Dock 中。启动成功后，请在屏幕顶部的菜单栏中寻找 Copie 图标。

## 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 左键长按且保持鼠标不动 | 全选当前内容 |
| 左键拖动选中文字，再点击右键 | 复制所选文字 |
| 点击鼠标中键 | 粘贴剪贴板内容 |

部分应用使用自定义文本控件，实际响应可能与普通 macOS 应用略有不同。

## 菜单栏设置

点击菜单栏中的 Copie 图标，可以使用以下设置：

- **触发时长**：调整左键需要按住多久才会执行全选，范围为 0.2–2.0 秒。可以拖动滑杆，也可以将鼠标放在滑杆上滚动滚轮。
- **登录时启动**：登录 macOS 后自动启动 Copie。
- **功能说明**：查看主要鼠标操作。
- **语言 / Language**：切换中文或英文界面。
- **Quit Copie**：退出 Copie，也可以按 `⌘Q`。

## 常见问题

### 操作没有反应

检查“系统设置 → 隐私与安全性 → 辅助功能”中的 Copie 开关是否已开启。如果已经开启但仍无反应，可以关闭开关后重新打开。

### 重新安装后权限失效

请确认 Copie 已放入“应用程序”文件夹。如果应用位置发生变化，macOS 可能会要求重新授权。

### 长按全选太快或太慢

点击菜单栏中的 Copie 图标，通过“触发时长”滑杆调整。默认值为 0.5 秒。

### 在 Dock 中找不到 Copie

这是正常现象。Copie 是菜单栏应用，只会显示在屏幕顶部的菜单栏中。

## 系统要求

- macOS 15.5 或更高版本
- Apple Silicon 或 Intel Mac
- 需要开启辅助功能权限
